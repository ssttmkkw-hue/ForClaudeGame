# 星陨战记 · Starfall Survivors

一款为**手机浏览器**设计的 Roguelike 生存动作游戏：单手拖动移动，武器自动攻击，
在怪潮中不断升级、进化武器，最终击败关底 Boss。纯原生 HTML5 / Canvas / WebAudio，
**无任何第三方依赖与素材文件**（美术与音效全部程序化生成），无需构建。

## 游玩

- 手机：按住屏幕任意位置拖动虚拟摇杆移动（设置里可切换"浮动 / 固定"摇杆）
- 电脑：`WASD` / 方向键移动，`Esc` / `P` 暂停
- 武器**自动攻击**；拾取经验宝石升级，三选一强化
- 右下角按钮释放主动技能（键盘：`空格` 冲刺、`Q` 大招）；靠近地图武器点「操控」（键盘 `F`）
- 地形对玩家和地面敌人同样生效：地面敌人用流场寻路绕行，蝙蝠/幽灵等飞行单位可直接越过；Boss 体型巨大会碾过障碍
- 右上角小地图显示地形、特殊区域、地图武器与精英/Boss 位置
- 关卡后 1/4 进入「狂潮」阶段：刷怪更密、敌人更快更强，精英成对出现
- 本地运行（任意静态服务器均可）：

```bash
python3 -m http.server 8000
# 手机与电脑同一 Wi‑Fi 下访问 http://<电脑IP>:8000
```

也可直接部署到 GitHub Pages / 任意静态托管，并"添加到主屏幕"以全屏游玩（含离线缓存）。

## 美术

全部美术由代码实时绘制并烘焙成贴图，零图片素材：

- **角色与怪物**：立体光影（受光/背光渐变、内阴影、高光、描边），逐帧动画（行走、扑翅、挤压回弹、漂浮），14 种体型 × 30+ 配色变体，8 名英雄各持专属武器
- **技能特效**：彗星拖尾魔弹、圣剑环拖尾、分叉闪电、法阵预警 + 陨石坠落 + 爆炸冲击波、冰晶新星、残影飞斧、冒泡毒池、流光射线；进化形态有独立配色
- **打击感**：命中火花、死亡碎裂与溅射、爆炸焦痕、升级光柱、弹跳伤害数字（位图字库）
- **场景**：可平铺噪声地面 + 世界坐标散布装饰（打破重复）、大型装饰物、关卡氛围粒子（萤火/风沙/飘雪/余烬）、暗角与色调光照
- **UI**：41 个统一风格的自绘图标（武器、进化、被动、强化、关卡）
- **性能**：贴图按需烘焙、阴影烘焙进动画帧、`setTransform` 批量绘制、按地图亮度控制发光强度、**动态分辨率**（帧率不足时自动降低内部分辨率）

## 代码结构

```
index.html          页面骨架（画布 + HUD + 界面容器）
css/style.css       手机优先样式（安全区适配、横竖屏）
js/util.js          工具函数与存档
js/data.js          武器 / 被动 / 角色 / 敌人 / 关卡 / 成就 数据（调数值改这里）
js/audio.js         WebAudio 音效与背景音乐合成
js/sprites.js       Canvas 矢量美术烘焙（敌人、英雄、地面、装饰、特效贴图）
js/vfx.js           粒子与特效（火花、爆炸、死亡、冰霜、升级、贴花）
js/icons.js         UI 自绘图标
js/input.js         触摸摇杆与键盘输入
js/map.js           有限地图：地形生成、碰撞、流场寻路、特殊区域
js/game.js          对局核心：空间网格、刷怪导演、Boss、掉落、升级、结算
js/weapons.js       8 种武器的行为
js/features.js      主动技能、地图武器、局内挑战、后期难度
js/quests.js        每日 / 主线任务
js/render.js        画布渲染
js/ui.js            菜单、商店、成就、设置、弹窗、HUD
js/main.js          入口与主循环
sw.js               离线缓存 Service Worker
```

## 调整数值

- 关卡难度：`js/data.js` 中 `SF.STAGES` 的 `hpMul / dmgMul / xpMul / rate` 与各 `waves`、`events`
- 武器成长：`SF.WEAPONS[*].base` 与 `lv[*].d`
- 经验曲线：`js/game.js` 中的 `xpNeed`
